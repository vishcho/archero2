# 超級明星盃規則

> 與**明星盃**是兩種不同賽事，勿混用：明星盃兩週一輪、有資格賽與 8 組淘汰賽；
> 超級明星盃四週一輪，為受邀制的高戰力賽事。完整對照見下方「與明星盃的差異」。

## 週期

| 項目     | 說明                                  |
| -------- | ------------------------------------- |
| 週期     | **四週一輪**                          |
| 時段     | 週四 – 隔週五（**9 天**）             |
| 近期輪次 | 7/9 – 7/17、8/6 – 8/14、9/3 – 9/11（推算） |

每輪有各自的**季主題**（如「精靈季 1」），決定該輪的核心流派與配置方向。

## 賽制

> 賽制細節尚未完整整理——目前收錄的是**選手配置**而非對陣結果。
> 補齊賽制前，本節僅記錄已確認的部分。

- 參賽者為高戰力選手，非全服開放報名。
- 賽事介面可查看參賽選手名單，配合好友 ID 查詢可取得個人配置。

## 資料收錄範圍

現階段每輪收錄一份**選手配置表**（`data/super-star-cup/{id}.json` 的 `roster`）：

| 欄位            | 說明                                             |
| --------------- | ------------------------------------------------ |
| `player_id`     | 遊戲內好友 ID                                    |
| `name`          | 角色名稱                                         |
| `spirit_awe`    | 精靈威攝裝備品階（`紅` / `金1`–`金3` / `未知`）  |
| `spirit_assist` | 精靈協戰裝備品階，值域同上                       |
| `enchants`      | 附魔陣列 `{ text, color }`，**索引即槽位**（見下） |

**空值與「未知」的區別**（重要）：

- 欄位**空缺** = 未取得該筆資料，不代表選手沒有。
- 值為 **`未知`** = 查詢過但介面未顯示。

兩者在頁面上分別顯示為 `—` 與灰色「未知」，避免把「沒查到」誤讀成「沒有」。

**`enchants` 的槽位對應**：陣列**索引即附魔槽位**（`enchants[0]` = 附魔 1）。
中間未取得的槽以 `null` 佔位、**不可壓縮**——否則後段詞條會位移到前面的槽，
變成「這人的附魔 1 是 X」這種錯誤結論。尾端空槽則直接省略（陣列短一點即可）。
`tools/validate-season.mjs` 會擋下尾端為 `null` 的寫法。

每格為 `{ "text": "詞條文字", "color": "紅" }`。

## 附魔品階對照

`color` 是**詞條本身的品階**（紅 > 黃），與選手無關——同一詞條在所有人身上必為同色。
`tools/validate-season.mjs` 會檢查這點，同一詞條出現兩種顏色會報錯。

| 品階 | 附魔詞條                                       |
| ---- | ---------------------------------------------- |
| 🔴 紅 | 精靈觸發連射時，必定觸發範圍子彈               |
| 🔴 紅 | 精靈爆擊率+30%                                 |
| 🔴 紅 | 精靈及其分身數量每增加1個，所有精靈攻速提升20% |
| 🔴 紅 | 精靈傷害+30%                                   |
| 🔴 紅 | 精靈暴擊傷害+30%                               |
| 🟡 黃 | 精靈及其分身數量每增加1個，所有精靈攻速提升10% |
| 🟡 黃 | 精靈傷害+15%                                   |
| 🟡 黃 | 精靈暴擊傷害+15%                               |

目前已知的詞條符合「**高數值紅、低數值黃**」：+30% 與 20% 攻速為紅，
+15% 與 10% 攻速為黃；「必定觸發範圍子彈」與「爆擊率+30%」為紅。
但這只是現有資料的歸納，**新詞條仍以實際介面顏色為準**，勿用數值推論。

新增未列於此表的詞條時，請一併補上對照，並確認顏色與既有資料一致。

## 與明星盃的差異

| 面向     | 明星盃                          | 超級明星盃                   |
| -------- | ------------------------------- | ---------------------------- |
| 週期     | 兩週一輪                        | 四週一輪                     |
| 賽制     | 資格賽 → 8 組 × 8 人淘汰賽 → 總決賽 | 受邀制（賽制待補）           |
| 參賽資格 | 全服開放                        | 高戰力受邀                   |
| 收錄資料 | 排名、對陣、逐場戰報            | 選手配置（精靈裝備與附魔）   |
| 資料 schema | `season`                     | `roster`                     |
| 資料位置 | `data/star-cup/`                | `data/super-star-cup/`       |
| 文件位置 | `docs/star-cup/`                | `docs/super-star-cup/`       |

兩者**不共用資料結構**，只在 `data/cups.json` 這層登記為兩個賽事系列。
