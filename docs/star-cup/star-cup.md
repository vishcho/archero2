# 明星盃規則

## 屆次定義（統一標準）

一屆明星盃 = **預選賽 4 天 + 其後淘汰賽 8 天**，共 12 天跨兩個週期。
預選賽產生的前 64 名就是**同屆**淘汰賽的參賽名單——兩階段屬同一屆，
講「第 N 屆」一律指這一整段。

| 概念            | 取值                                    | 第 5 屆（本屆） |
| --------------- | --------------------------------------- | --------------- |
| 屆次序號 `round`| 2026 年起累計                           | 5               |
| 屆次 id         | **淘汰賽首日**（識別碼，非該屆起始日）  | `2026-08-14`    |
| 預選賽期間      | 週一 – 週四（4 天）                     | 8/10 – 8/13     |
| 淘汰賽期間      | 週五 – 隔週五（8 天）                   | 8/14 – 8/21     |

> **id 為何不是該屆首日**：id 沿用淘汰賽首日，因為排名、對陣、逐場戰報全部
> 產生自淘汰賽，且既有檔名與外部連結都建立在此。談「該屆起始日」一律指
> 預選賽首日，讀 `qualifier_period[0]`，**勿從 id 推論**。
> `tools/validate-season.mjs` 會強制 `id === knockout_period[0]`。

**主題有兩層**，`data/star-cup/{id}.json` 分成兩個欄位，皆可為 `null`：

| 欄位     | 語意                         | 例                       |
| -------- | ---------------------------- | ------------------------ |
| `theme`  | 該屆的流派主題               | `飛劍x元素`              |
| `season` | 跨屆的季主題（數屆共用）     | `精靈季`                 |

`theme` 一律記成 **`流派Ax流派B`** 的簡化寫法：截圖頂部的原句是「獲得精靈和飛劍
流派技能」，只取兩個流派名、以半形小寫 `x` 相接，寫成 `精靈x飛劍`。不保留「獲得」、
「和」、「流派技能」等贅字，也不加空白。流派名照截圖原字，不自行翻譯或縮寫。

第 3～5 屆同屬「精靈季」，各屆流派主題依序為 `精靈x主武器`、`精靈x旋轉球`、
`精靈x飛劍`。第 1、2 屆同屬「飛劍季」，依序為 `飛劍x元素`、`飛劍x流星`。
季主題與屆主題應分別記入 `season` 與 `theme`，不可把季主題塞進屆主題欄位。
超級明星盃**不分兩層**——它一輪一個主題，沿用單一 `theme` 欄位（如 `精靈季 1`）。

## 賽制流程

| 階段       | 說明                                                                  |
| ---------- | --------------------------------------------------------------------- |
| **資格賽** | 全員參加，排行榜前 **64 名**晉級淘汰賽；排名依據：通關層數 + 完成時間 |
| **淘汰賽** | 64 人分為 **8 組**，每組 8 人對戰；每組**第一名**晉級決賽             |
| **決賽**   | 8 名晉級者**兩兩對決**，最終勝者奪得冠軍                              |

## 競猜功能（淘汰賽 & 決賽適用）

| 結果     | 獎勵                                      |
| -------- | ----------------------------------------- |
| 競猜成功 | 獲得投注競猜幣 **×1.5** 的明星徽章        |
| 競猜失敗 | 獲得投注競猜幣 **×0.5**（一半）的明星徽章 |

> 下注所需競猜幣金額會依賽事階段調整。

## 注意事項

- 賽事有時間限制，**未按時參賽視為棄權**。

## 資格賽排名規則（優先順序）

| 優先級 | 判定條件                   | 說明                         |
| ------ | -------------------------- | ---------------------------- |
| 1      | **最高關卡進度**           | 進度越高排名越前             |
| 2      | **對最終 BOSS 造成的傷害** | 擊殺數相同時，傷害較高者優先 |
| 3      | **通關時間**               | 傷害相同時，時間較短者優先   |
| 4      | **達成先後順序**           | 以上全部相同時，先達成者排前 |

- 資格賽排行榜僅用於晉級判定，**不發放排行榜獎勵**
- 僅顯示前 **1000 名**

## 淘汰賽排名規則

| 名次     | 條件                                                         |
| -------- | ------------------------------------------------------------ |
| 第 1 名  | 冠軍                                                         |
| 第 2 名  | 亞軍                                                         |
| 第 3 名  | 季軍賽勝者                                                   |
| 第 4 名  | 季軍賽敗者                                                   |
| 其餘名次 | 依淘汰賽**勝場數**排名；勝場相同則依**資格賽成績**較佳者優先 |

> 排名獎勵於決賽結束後透過**郵件**發放。
