# 聯盟寶藏規則

活動期間使用道具【聯盟寶藏圖】，為整個聯盟開啟一張限時 24 小時的挖寶圖，
聯盟成員共同挖掘、各自領獎。

> 來源：遊戲內「規則說明 / Rules」彈窗，2026-08-15 擷取（該次活動剩餘 27 天 21 小時）。
> 原圖見 `screenshots/alliance-treasure/2026-08-15/`（截圖不進 git）。

## 兩層時間

聯盟寶藏有**兩個獨立的計時**，混淆會導致開圖被白白清空：

| 計時         | 長度        | 歸誰      | 結束時                       |
| ------------ | ----------- | --------- | ---------------------------- |
| 活動期間     | 約 28 天    | 全服活動  | 無法再使用【聯盟寶藏圖】     |
| 單張藏寶圖   | 24 小時     | 該張圖    | 圖自動消失                   |
| 聯盟更新     | 依遠征分組  | 聯盟編制  | **所有未結束的圖一律清空**   |

**聯盟更新優先於 24 小時期限。** 一張剛開的圖若碰上公會遠征分組刷新，
不論還剩幾小時都會被清掉——這是規則裡唯一會造成實質損失的機制。

## 聯盟編制

- 活動開啟後，系統依**本期公會遠征的分組**自動組成「聯盟」。
- 無法參與遠征的公會，視為一個**獨立聯盟**。
- 下一次遠征分組刷新時聯盟重組，同時清空所有進行中的藏寶圖。

## 開圖

| 項目     | 規則                                             |
| -------- | ------------------------------------------------ |
| 道具     | 【聯盟寶藏圖】，於背包內使用                     |
| 影響範圍 | 為**整個聯盟**開啟一張新圖，不是只給自己         |
| 圖的大小 | 依**公會段位**而定，段位越高圖越大               |
| 使用限制 | 僅限活動期間；非公會成員無法使用                 |
| 二次確認 | 距聯盟更新不足 **10 小時**時，使用前會跳確認     |

## 挖掘

- 聯盟內所有玩家皆可參與挖掘。
- **每位玩家對每張藏寶圖只能挖一次**——想多拿獎勵靠的是聯盟裡有人持續開新圖，
  不是自己重複點。
- 挖到寶藏獲得獎勵；挖到空格沒有收益。
- **加入新公會後，無法挖掘加入前已觸發的聯盟寶藏。**

## 操作重點

1. **開圖看時鐘**：距聯盟更新剩不到 10 小時就別開新圖。遊戲會跳二次確認，
   那個提示的實際意思是「這張圖活不滿 24 小時」。
2. **開圖是公共財**：道具消耗在自己身上，圖開給全聯盟。聯盟內協調開圖節奏，
   比各自囤圖有效率。
3. **段位就是期望值**：公會段位直接決定圖的格數，也就決定整個聯盟的可挖總量。
4. **轉會前先挖完**：換公會會失去所有加入前已觸發之藏寶圖的挖掘權，
   要跳槽就先把手上的圖挖掉。

## 介面

| 位置       | 內容                                                       |
| ---------- | ---------------------------------------------------------- |
| 頂部       | 活動剩餘時間（如「剩餘時間:27天21小時」）                   |
| 左上寶箱   | 當前藏寶圖剩餘時數（如「23小時」）                          |
| 橫幅       | 最近挖到寶藏的玩家（如「CoBa發現的寶藏！」）                |
| 格子       | 綠色為未挖；已挖出者顯示道具圖示（權杖、皇冠、箭袋、寶箱等）|
| 底部       | 「點擊任意寶藏格挖掘」                                      |
